# PackTrail 5분 시연 구성 초안

목표 길이 4분 30초. 화면은 가상 제품과 가상 성적서만 사용하며, 실제 구현과 리허설 결과에 맞게 문구를 최종 수정한다.

| 시간 | 화면과 행동 | 설명 |
|---|---|---|
| 0:00–0:30 | 문제 소개 | “포장재 담당자는 재질과 용도, 판매 지역에 따라 자료를 찾고 시험성적서와 대조해야 합니다. PackTrail은 이 과정을 제품별 검토 흐름으로 정리합니다.” |
| 0:30–1:15 | EU 가상 식품 용기 입력 | “판매 지역, 포장 형태, 재질과 코팅을 선택하고 식품 접촉·온도·시간을 입력합니다. 모르는 정보는 비워두면 확인할 항목으로 남습니다.” |
| 1:15–2:00 | 내부 자료 결과와 부족 정보 | “내부 자료를 먼저 확인하고 제품 정보, 부족한 조건, 다음 조치와 출처를 보여줍니다. Liner Router가 입력을 분석하고 Rerank가 내부 후보의 관련도 정렬을 돕습니다.” |
| 2:00–2:45 | Liner 추가 검색 및 출처 | “내부 근거가 부족하면 추가 검색 여부를 묻습니다. 동의하면 Liner가 외부 자료를 찾아 출처를 보여주고 검토 후보로 보관합니다.” 실제 검색 성공 화면을 확인해 녹화한다. |
| 2:45–3:40 | 가상 성적서 및 결과 | “가상 PDF에서 시험 항목과 원문 위치를 확인합니다. 현재 수치 자동 비교는 EU PPWR의 두 항목에 한정하며 조건이 부족하면 보류합니다.” 실제 업로드와 결과를 리허설한다. |
| 3:40–4:05 | SB 54 업무 선택 | “SB 54에서는 시험값뿐 아니라 포장 방식과 사업자 역할을 함께 확인하도록 질문이 바뀝니다.” |
| 4:05–4:30 | 범위와 확장 | “결과는 검토를 돕는 예비 안내입니다. FCM 시험별 기준과 생산자책임 검토를 확장하고, 같은 가상 제품을 기준으로 수동 조사 시간과 비교하겠습니다.” |

녹화 전: 실제 제품·회사명·고객 정보·개인정보와 API 키가 보이지 않는지 확인한다. AI 호출이 실패하면 성공한 것처럼 시연하지 않는다. 시연 승인 자료는 내용 미검증임을 밝힌다.
