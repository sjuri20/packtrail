# PackTrail

포장재 담당자가 제품 조건을 정리하고 관련 규제, 실무 고려사항과 준비 서류를 찾도록 돕는 Liner 기반 시연용 웹 앱입니다.

## 실행

1. Node.js 22.13 이상을 설치합니다. (권장: Node.js 24 LTS)
2. `.env.example`을 복사해 `.env`로 저장하고 `LINER_API_KEY`에 심사용 Liner Platform 키를 입력합니다. 키는 소스나 공개 저장소에 올리지 않습니다.
3. 이 폴더에서 `npm start`를 실행하고 브라우저에서 `http://127.0.0.1:8787`을 엽니다. 별도 패키지 설치는 필요하지 않습니다. OCR 등 브라우저 라이브러리는 인터넷이 필요합니다.

처음 실행 시 공개 기초자료를 로컬 SQLite에 저장하고 **시연을 위한 내용 미검증 승인**으로 표시합니다. 승인 상태는 기능 검증용이며 법령이나 자료의 정확성을 보증하지 않습니다. 로컬 저장소는 `var/`에 생성됩니다. 앱은 현재 컴퓨터에서만 접속되도록 실행되며 인증이 없는 시연 환경이므로 외부 공개 서버로 그대로 사용하지 마세요.

## Liner API 활용

제품 및 질문 분석과 내부 자료 검색 보조, 추가 규제 검색과 실무 제안, 업로드한 성적서의 시험 항목 추출 및 잔액 확인에 사용합니다. API 키가 없거나 호출이 실패하면 일부 분석은 대체 방식으로 표시되며 추가 검색은 사용할 수 없습니다. 입력 내용과 관련 자료 일부는 Liner에 전달될 수 있으므로 시연에는 가상 또는 공개 자료만 사용하세요.

## 시연과 한계

시장, 용도와 재질 등을 입력하면 내부 승인 자료를 먼저 찾고 검색 결과와 실무 검토 항목을 보여줍니다. 필요할 때 Liner 추가 검색을 요청할 수 있습니다. PDF 성적서의 텍스트 또는 OCR 인식 결과를 검토할 수 있습니다. 자동 수치 비교는 현재 구현된 제한적 EU PPWR 기준에만 적용되며 FCM과 SB 54 전체의 적합 여부를 자동 확정하지 않습니다. 성적서 인식과 결과는 사람이 확인해야 하며 법률 자문이나 인증을 대체하지 않습니다.

정기검색의 설정과 실행 기능은 포함되어 있지만 이 로컬 실행 방식에는 자동 스케줄러가 연결되어 있지 않습니다. 외부 스케줄러와 지속적인 저장소 연결이 추가로 필요합니다.

Vercel 공개 시연은 Supabase 환경 변수가 설정되면 Liner가 찾은 출처의 제목·주소·요약을 저장하고 다음 검색에 재사용합니다. 수집한 자료는 검토 전 자료로 표시하며 검색어와 생성 답변 원문은 저장하지 않습니다. 저장소에 연결할 수 없으면 기본 자료만 검색하고 화면에 알립니다. 자료 승인 관리와 정기검색은 아직 연결되지 않았습니다. 공유 Liner API 키는 설정하지 않았으므로 사용자가 직접 입력해야 합니다. Supabase 서비스 키는 Vercel 서버 환경에만 설정해야 합니다.

## 기존 작업과 해커톤 개발

기존 RecySpec/RecyPack 프로젝트에서 포장재 규제 조사 아이디어와 사전 준비 자료를 이어받았습니다. 이번 PackTrail은 별도의 웹 앱으로 제품 조건 입력, 내부 자료 우선 검색, Liner 연동, 자료 검토, 성적서 검토 및 시연 흐름을 구현했습니다. 기존 프로젝트의 전체 저장소나 백업은 이 제출용 저장소에 포함하지 않았습니다.

기획서와 시연 대본은 `docs/`에 있습니다. 기초자료의 출처 링크는 `data/official_base.json`과 앱에서 확인할 수 있습니다.
